# 👥 Ask People Team

Welcome to the **People Team** documentation hub for Mainstay. This repository is the single source of truth for all HR-related policies, procedures, and resources. Whether you're a new hire getting oriented or a team member looking up a specific policy, you'll find everything you need here.
